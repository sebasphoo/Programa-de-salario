# SOBREESCRITURA METODOS POO
La sobreescrirura de metodos poo es cuando una clase hija redefine un metodo heredado de una clase padre para darle un coportamiento diferente.

## PARAMETROS POSICIONALES
Son aquellos que se envian respetando el orden en que fueron definidos en la funcion.

## PARAMETROS NOMBRADO
SON AQUELLOS EN LOS QUE SE ESPECIFIFCA EL NOMBRE DEL PARAMETRO AL MOMENTO DE LLAMAR LA FUNCION
